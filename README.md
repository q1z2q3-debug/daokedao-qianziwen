# 润泽说 蒙学之千字文

《千字文》全文通释，亲子共读。全书三十三课，依句意分课，不硬拆五十课。

- 阅读版：<https://q1z2q3-debug.github.io/daokedao-qianziwen/>
- 正文：一千字，三十三课
- 体例：原文 · 字源 · 直译 · 深解 · 对课 · 生活场景 · 亲子问 · 写字 · AI形象字 · 全课字墙 · 跨典
- 末课专题：字源演化 · 甲骨到今字（五字甲骨原形，四十字演化解读）
- 附录一：识字，从甲骨文开始；附录二：甲骨文常用字 · 一百二十字详解（每字含 SVG 字形、合集号/著录号、取象解释与课次）
- 核验：`book/甲骨文溯源核验-一百二十字.md`（殷契文渊逐字检索，102/120 检出；未检出者已改标）

## 插图

全书 64 幅无字满幅画，每课原文之后即为题图：纸色 #EFE7D6，墨、赭石、花青三色，人物只作侧影背影，画面不题一字。题注取该幅对应的原文句；画不是注解，是让孩子先把景象看见，再读字。

## 怎么读

先读原文，不看解释；再看字源，知道这个字本来想抓住什么；再看直译与深解；最后对一句、写两个字。

课末“AI形象字 · 全课”把本课原文逐字铺成单线手绘字墙：有甲骨、金文、小篆或古文字形者，取其骨架转写；未见古文字形者，以今字骨架自创。它不是甲骨文复原，是借字的结构做的一组可读的画。附录讲真甲骨文的来历，两者分开看。

## 说明

- 不是五十课。课界按句意，遇到气脉相连的句子就并课。
- 不做虚构故事，不把字源讲成神话；有异说的字，正文里标“有异说”。
- 被否定的稿子不销毁，另存并标“存疑”。
