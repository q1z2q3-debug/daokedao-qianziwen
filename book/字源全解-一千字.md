# 字源全解 · 一千字

体例：一、正文本课字源只解每课八至十二个关键字；二、此表补足全书一千字，一字一条：本义在前，构形取甲骨、金文、小篆之一，引申只列正文用到的义；三、构形有异说的，写明「一说」，不冒充定诂。

## 第一课　天地玄黄

| 字 | 本义 | 构形 | 引申 |
|---|---|---|---|
| 天 | 头顶之上 | 甲骨文、金文在「大」（人形）上加一横 | 天空 |
| 地 | 大地 | 从土、也声（小篆） | 土地 |
| 玄 | 幽远 | 小篆从幺，象丝缕幽微 | 黑中带赤的天色 |
| 黄 | 土色 | 甲骨文构形有异说，取「土黄」一义 | 中央之色 |
| 宇 | 屋檐 | 从宀、于声（小篆） | 上下四方 |
| 宙 | 久远 | 从宀、由声；《说文》「舟舆所极覆也」 | 往古来今 |
| 洪 | 大水 | 从水、共声 | 水未退之世 |
| 荒 | 草掩其地 | 从艸、巟声 | 未开垦之地 |
| 盈 | 器满 | 从皿、夃（小篆） | 月圆 |
| 昃 | 日西斜 | 从日、仄声；《说文》「日在西方时侧也」 | 日过中天 |
| 日 | 太阳 | 甲骨文象日轮，中加一点或一横 | 一日、白天 |
| 月 | 月亮 | 甲骨文象半月之形 | 月份 |
| 辰 | 蚌壳、星 | 甲骨文象蚌壳之形（辰为蜃之初文） | 星辰、时辰 |

| 列 | 分解、排列 | 从刀、从歺（小篆） | 行列 |
